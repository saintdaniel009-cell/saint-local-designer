# Brand: Generic (client work with no brand file yet)
Frame 390 × 844. Clean, neutral, modern.
- Fonts: "ui" and "display" are both Inter. Titles 28 bold, body 15, tracking -1.
- Primary colour "brand"; neutrals "ink", "muted", "line", "surface".
- Buttons 52 px, radius 12. Cards radius 16, fill "surface".
To add a client: copy this file and generic.tokens.json to brands/<client>.md and brands/<client>.tokens.json, then run with --brand <client>.
